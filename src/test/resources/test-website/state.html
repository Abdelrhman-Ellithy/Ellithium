State & Interactivity Traps

Elements that are unclickable due to z-index overlays, disabled/readonly state, off-screen positioning, and rapid attribute mutation cycles. Each scenario maps to a specific Selenium exception that the Ellithium InteractionRecovery layer must handle.

🔒 Transparent Z-Index Overlay Trap
A fully transparent div sits on top of the button with a higher z-index. Selenium's click() will throw ElementClickInterceptedException. Use JavascriptExecutor to bypass or remove the overlay first.

🔐 Disabled & ReadOnly Inputs
Fields start locked. Toggling the checkbox enables them. Tests InvalidElementStateException when attempting to clear/type into a disabled or readonly field.

📡 Off-Screen Element (left:-9999px)
The element #offscreen-element permanently lives at left:-9999px. findElement succeeds but any interaction throws ElementNotInteractableException. Use JavascriptExecutor.scrollIntoView to bring it on-screen.
