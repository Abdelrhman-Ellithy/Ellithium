📦 Dynamic iFrame — 3-Second Delayed Injection
The <iframe> element is not present in the DOM at page load. It is injected exactly 3 seconds after. Any attempt to driver.switchTo().frame() before injection throws NoSuchFrameException. After injection, use WaitActions.waitForFrameToBeAvailableAndSwitchToIt(). The iframe contains a full login form that requires frame context to interact with.
